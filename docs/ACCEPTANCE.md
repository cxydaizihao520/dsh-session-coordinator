## 包装修复与边界

`prepare` 原先只运行 tsdown，Git 来源安装缺少清单声明的 `lib/types/index.d.ts`。本候选改为复用已有 `pnpm build`，由同一构建同时生成类型和宿主 JS；没有增加依赖或另一套构建脚本。

源码构建使用 pnpm 10.30.3；宿主自带安装器实际使用 pnpm 11.28.5。Git 来源需按安装器打印的准确 `allowBuilds` 键批准构建；不要全局允许任意脚本。预构建 tgz 不需要这项 Git prepare 授权。

公开客户端套件明确跳过八个私人历史回放用例，另外十个私人运行轨迹审计用例不进入公开默认套件；本次不是这些历史用例的通过证明。源代码按锁定的 rc.1 类型检查；rc.5 应用归档没有附带声明文件，本次 rc.5 结论来自真实原生运行与浏览器验收，不冒称 rc.5 完整静态类型兼容。

忙时长工具、十轮改测、全部取消／恢复分支、图片语义、压缩后接手、Git 工作树与集成，以及 Electron desktop profile 没有在本轮完整重测。本插件参考 Codex 的独立会话协作方式，不宣称完全等价。
