# 使用场景与示例

适用于 0.2.2 源码试用版。先按[安装手册](./INSTALL.md)安装并核对版本。以下示例可以直接发给 Harness，不需要填写内部会话 ID 或工具名。

## 先选协作方式

- **单次交办**：把一件事交给另一个会话，完成后回信一次。
- **持续协作**：明确目标与参与会话，首次范围审批后自动分工、反馈、修改和复核，直到验收完成或遇到需要处理的停止条件。
- **仅同步信息**：说明“仅供参考、不需要回复”，把信息留作上下文；空闲会话不会为此专门起一个任务。

明确要求“新独立主会话”时，应在侧栏出现一个可独立打开、有自己历史的聊天。临时子智能体属于不同工作方式。

## 九类常用需求

| 需求 | 可以直接这样说 | 如何检查结果 |
|---|---|---|
| 总控 + 多个会话 | 你当总控，新建实现、审查两个独立会话，完成一个可运行交付；按审查意见修改、复核通过后交给我。 | 有指定参与会话，实际产生交付、审查与后续反馈，总控最后验收。 |
| 派新会话做事 | 派一个新的独立主会话，命名“方案复核”，检查这份方案并回信。 | 侧栏出现“方案复核”，打开能看到其任务和实际结果。 |
| 发给已有会话 | @会话B，把接口核验交给它，完成后回复这里。 | 发送目标是所指会话，结果回到当前聊天；同名目标应先消歧。 |
| 仅同步信息 | 把这个决定同步给会话B，仅供参考，不需要回复。 | B 留存原文，不为信息单独起任务或自动回信。 |
| 同步历史集合 | 把刚才讨论的最新结论，同步给前面提到的A、B、C这几个会话。 | 接收集合与前文一致；指代不清时先确认。 |
| 同步运行中会话 | 把新的接口约定同步给当前工作区其他正在运行的会话，仅供参考。 | 按发送时的运行状态筛选，排除当前聊天，并报告逐目标结果。 |
| 同步未归档会话 | 把这份结论同步给当前工作区其他未归档会话，仅供参考。 | 排除自身和已归档会话，包含空闲会话；不会为信息专门唤醒它们。 |
| 忙时承接回信 | 交给B核算调整项，你继续处理销售主账；收到它的真实结果后合并，再交给它复核。 | B 在 A 工作中回信；A 当前工具正常完成，在后续步骤使用回信继续。 |
| 控制协作过程 | 暂停审查任务，实现继续；告诉我各项进展。 | 控制针对指定任务，不连带取消无关工作；报告实际状态。 |

`@B 看看它之前说过什么` 是读取历史，`@B 把这件事交给它` 才是发送任务。未明确接收范围时，先澄清范围，不把一次同步变成长期订阅。

## 三个完整案例

### 代码实现与独立审查

> 你作为总控，新建“CSV实现”和“CSV审查”两个独立主会话。在我指定的示例目录交付 Python 标准库 CSV 校验工具、测试和中文说明。实现者先交可运行初版，审查者实际运行并给出有证据的意见；有缺陷则修改后复审，无缺陷则补一个有价值的边界用例。任务内允许自动多轮沟通，最后由你整合并验收。不安装依赖、不修改宿主或插件。

检查代码、测试输出及审查意见是否真正改变交付；一句“已完成”不代替文件和运行证据。

### 销售主账与中途回信

> 在我准备的验收目录里，你处理销售主账，同时新建独立主会话“调整核算”，让它只读核算调整项，完成后立即回信。你派出任务后继续执行主账批处理，不等回信、不取消当前命令。命令结束后结合真实回信生成合并报告，再让同一个会话独立复核，依据反馈完成验收和协作收尾。只操作这个目录，不联系其他会话。

0.2.2 桌面已有实际样本：A 前台处理 20 万笔销售，约 60 秒；B 在约第 11.8 秒返回净调整 13.15。A 正常完成工具后同轮继续，合并为 101013.15，再交 B 复核和确认。最后收尾出现一次遗漏结果 ID 的工具参数错误，模型自行纠正；不是全程零错误承诺。

### 十轮滚动库存

> 你当总控，新建独立主会话“库存核算”，自动往返十轮。初始库存100，第n轮入库3n、出库n+1。每次只派当前一轮，让对方实际计算并回信；你核对后才把真实结存作为下一轮期初，不能一次派十轮或把一封回信写十行冒充往返。首次范围审批后无需我逐轮发话。十轮后给我实收库存表，验收并结束协作。不读写文件。

预期结存：101、104、109、116、125、136、149、164、181、200。必须检查十次实际请求与回信；算出200不等于完成十次往返。真实 Harness 的单任务十轮和桌面的同范围十次往返均有成功样本，未触发第三跳拦截，模型参数错误与自行纠正按实际保留。

## 审批、呈现与试用边界

首次范围审批覆盖明确目标、成员和预算；后续工作沿该范围推进。暂停、取消、明确拒绝、预算用尽或未知执行状态需要按实际原因处理。旧单次消息链仍只有一次回信权，不能借旧回信自动扩大持续授权。

收信卡显示会话名称，提供“复制正文”和“查看来源会话”。名称缺失时显示占位；准确身份和原生记录保留。切换聊天可直接查看对方实际工作。

单次交办、持续多轮、总控与多个协作者、忙时回信已有真实运行样本。群体同步有历史桌面样本，0.2.2 尚未逐项重测；暂停/恢复等组合控制未全部做桌面验收。附件语义、工作树与全部 Codex 用户旅程继续按各自验证边界，不承诺完全等价或模型零错误。
