# 会话协作使用示例

- **传递上下文**：把这份结论发给“实现评审”会话，供它下次处理时参考。
- **发起协作**：新建独立会话核对这些数据。回到当前会话时给我结果和还需要确认的事项。
- **多会话分工**：请实现会话做修改，测试会话独立复核。让他们在这次获批的范围内交换结果，完成后告诉我结论。

首次需要授权时，在 Harness 审批界面核对参与者、用途和操作范围。接纳投递、对方读取和工作完成是三个不同状态。撤销权限、撤回未消费消息和停止执行分别处理。会话头部可导出本地诊断，分享前先检查其中的会话标识。

默认入口与进阶说明见[项目介绍](../README.md)。预览版的覆盖范围见[验收说明](ACCEPTANCE.md)。
